# 일정 출처

스케줄 탭에서 전체 / Mnet Plus / blip을 선택합니다. 선택은 같은 브라우저에 저장되며, 캘린더·검색·일정 내보내기에 함께 적용됩니다. 직접 등록한 일정과 센플릭스의 생일·기념일은 공통으로 표시됩니다. 메뉴의 가까운 일정은 출처 선택과 관계없이 전체 일정을 표시합니다.

전체 보기에서 날짜·시간·제목이 같은 일정은 한 번 표시하고 두 출처를 함께 적습니다. 제목의 공백과 꺾쇠 표기는 정규화하지만, 시간이나 제목이 다른 일정은 임의로 합치지 않습니다.

## 수집

기존 명령을 그대로 실행합니다.

```sh
python crawlers/crawl_schedule.py
```

- Mnet Plus: 기존처럼 이번 달과 다음 달을 확인합니다.
- blip: 지난달부터 두 달 뒤까지 공개 스케줄 페이지를 확인합니다. 로그인, 쿠키, API 키를 사용하지 않습니다.
- 기존 네이버 뉴스 수집은 그대로 유지합니다.
- 기존 workflow_dispatch와 외부 cron-job 설정은 변경하지 않습니다.

월별 수집이 성공하면 해당 출처·해당 월만 교체합니다. 요청 실패나 형식 오류가 나면 그 출처의 기존 일정은 남겨둡니다. 정상적으로 확인된 빈 목록은 해당 출처·해당 월 일정을 비웁니다. 일정 내용이 같으면 반기 JSON을 다시 쓰지 않습니다.

블립 시간은 한국 시각으로 변환합니다. 여러 날에 걸친 일정은 블립 화면과 같이 종료일을 포함해 날짜별로 표시합니다. 같은 일정 ID와 날짜는 중복 저장하지 않습니다. 내보내기도 화면에 표시하는 날짜별 일정을 사용합니다.

공개 페이지 구조 변경 시 블립 파서 수정이 필요할 수 있습니다. 403 등 요청 실패는 로그에 남으며 기존 데이터를 지우지 않습니다. 최신 수집 성공을 보장하는 상태 표시로 해석하면 안 됩니다.
